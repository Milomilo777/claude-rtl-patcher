01 / Features

A simpler path from install to launch.

Aa

Persian typography

Vazirmatn typography for clearer conversations and a more polished Claude UI.

↔

Smart RTL mode

Detects the Claude version and applies full RTL only when native support is not already available.

⌘

Safe and reversible

Creates a backup, updates macOS integrity metadata, and includes a restore path.

02 / Install

One command. Everything handled.

Since v1.1.2, standalone binaries are published for the main desktop targets — no Node.js required.

curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/claude-rtl-patcher/main/install.sh | bash
irm https://raw.githubusercontent.com/m4tinbeigi-official/claude-rtl-patcher/main/install.ps1 | iex

The installer detects Claude, creates a backup, and launches the patch menu.

03 / Support

Clear about limitations.

Supported

macOS Intel / Apple Silicon · Windows x64 · Linux x64

Windows MSIX limitation

WindowsApps is TrustedInstaller-owned; MSIX installs are intentionally rejected instead of failing halfway.
